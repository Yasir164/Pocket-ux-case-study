# Pocket — Personal Finance & Budgeting App for Everyone

**Platform:** iOS + Responsive Web &nbsp;|&nbsp; **Tools:** Figma + HTML/CSS/JS &nbsp;|&nbsp; **Duration:** Jan–Feb 2026

---

## Overview

Pocket is a mobile app, responsive website, and fully coded interactive prototype designed to solve a universal problem: not knowing where your money goes. It adapts its budgeting model to how users actually earn — salary, allowance, freelance, or pension — making it the first personal finance tool structurally inclusive of students, freelancers, couples, and retirees.

A moderated usability study with 5 participants produced P0/P1/P2 findings directly shaping the second iteration. AI tools were used throughout design and research.

---

## Usability Testing Results

| Priority | Issue | Fix |
|---|---|---|
| P0 | FAB for Add Expense missed by 5/5 participants | Sticky 'Add expense' button above nav bar |
| P0 | Income mode options unclear to 3/5 participants | Plain-English descriptions + 'Change later' label |
| P1 | Budget categories too generic | Allow custom category naming in setup |
| Strength | Chart-first dashboard praised by all 5 | Preserved and made primary in revision |

---

## Coded Prototype Features

- Working numpad for expense entry with real-time amount display
- Category selector grid with visual active state
- Budget impact preview card updating with entered amount
- Searchable and filterable transaction list
- Saving goals with progress bars and add funds interaction
- Shared budget with settle-up flow and member contribution bars
- Monthly spending trend SVG chart
- Full onboarding: Sign Up → Income Mode → Category Setup → Dashboard
